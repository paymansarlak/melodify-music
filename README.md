# Melodify — پخش‌کننده موزیک

یک اپلیکیشن موزیک پلیر مدرن، ساخته‌شده فقط با **HTML5 + CSS3 + Vanilla JavaScript** (بدون هیچ فریم‌ورک یا کتابخانه‌ای).

## ویژگی‌ها

- پخش/توقف، آهنگ قبلی/بعدی، پخش خودکار آهنگ بعدی
- نوار پیشرفت با قابلیت seek (کلیک/درگ) + نمایش زمان mm:ss
- کنترل ولوم + میوت/آنمیوت
- جستجوی آنی بر اساس عنوان و خواننده (بدون‌حساسیت به بزرگ/کوچک بودن حروف) با حالت «چیزی پیدا نشد»
- کتابخانه‌ی موسیقی با ۱۰ آهنگ نمونه (عنوان، خواننده، آلبوم، ژانر، مدت‌زمان، کاور، فایل صوتی)
- موردعلاقه‌ها (❤) با ذخیره‌سازی در `localStorage`
- اخیراً پخش‌شده با ذخیره‌سازی در `localStorage` (بدون تکرار غیرضروری)
- ادامه‌ی پخش: آهنگ و موقعیت پخش آخرین بازدید بازیابی می‌شود
- Shuffle (بدون تکرار آهنگ تا وقتی همه پخش نشدن)
- Repeat سه‌حالته: خاموش / تکرار همه / تکرار یک آهنگ
- کلیدهای میانبر صفحه‌کلید:
  - Space → پخش/توقف
  - → → جلو بردن ۵ ثانیه
  - ← → عقب بردن ۵ ثانیه
  - ↑ → افزایش صدا
  - ↓ → کاهش صدا
  - N → آهنگ بعدی
  - P → آهنگ قبلی
  - (میانبرها هنگام تایپ در کادر جستجو غیرفعال می‌شوند)
- حالت تیره/روشن با ذخیره‌سازی در `localStorage` و انتقال نرم
- پیمایش تک‌صفحه‌ای: خانه / کشف موسیقی / موردعلاقه‌ها / اخیراً پخش‌شده
- حالت‌های خالی حرفه‌ای برای جستجو، موردعلاقه‌ها و تاریخچه
- مدیریت خطای پخش (فایل صوتی یافت‌نشد → پیام، بدون کرش)
- کاملاً ریسپانسیو (موبایل، تبلت، دسکتاپ) بدون اسکرول افقی
- دسترسی‌پذیری: HTML سمانتیک، aria-label، فوکوس قابل‌مشاهده

## تکنولوژی‌ها

- HTML5
- CSS3 (متغیرها، Grid/Flexbox، انیمیشن)
- Vanilla JavaScript (بدون فریم‌ورک)

## ساختار پروژه

```
melodify/
├── index.html          ساختار اصلی صفحه
├── style.css            استایل کامل (تم تیره/روشن، ریسپانسیو)
├── script.js             منطق برنامه (پخش، جستجو، localStorage، ...)
├── assets/
│   ├── music/            فایل‌های mp3
│   └── images/           عکس‌های کاور
└── README.md
```

## نحوه‌ی اجرا

1. پروژه را دانلود/کلون کن.
2. فایل‌های صوتی خودت را (قانونی) داخل `assets/music/` بگذار و عکس‌های کاور را داخل `assets/images/`.
3. آرایه‌ی `songs` در ابتدای `script.js` را با اطلاعات واقعی آهنگ‌هایت به‌روزرسانی کن (title, artist, album, genre, duration, src, cover).
4. فایل `index.html` را در مرورگر باز کن.

> نکته: برای سازگاری کامل با همه‌ی مرورگرها (به‌خصوص هنگام پخش فایل‌های صوتی محلی)، توصیه می‌شود پروژه را از طریق یک سرور محلی اجرا کنی، مثلاً:
> ```
> npx serve .
> ```
> یا
> ```
> python -m http.server
> ```

## نمونه آهنگ‌های داخل پروژه

فایل‌های mp3 داخل `assets/music/` با یک سازدهنده‌ی MIDI واقعی (FluidSynth + بانک صدای General MIDI) رندر شده‌اند — یعنی صدای هر ساز از نمونه‌برداری واقعی همون ساز میاد، نه یک بوق سنتتیک ساده. هر آهنگ یک ساز مشخص داره:

| آهنگ | ساز |
|---|---|
| بارون بهاری | پیانو آکوستیک |
| شب آرام | فلوت |
| رویای دور | ویولن |
| لحظه‌های ساده | گیتار کلاسیک (نایلون) |
| آسمون آبی | ماریمبا |
| خاطره‌ها | کلارینت |
| جاده‌ی نور | ترومپت |
| نسیم شرقی | فلوت پن (نی شرقی) |
| ستاره‌ی من | ویبرافون |
| پاییز عاشق | ویولن‌سل |

این‌ها ملودی‌های کوتاه تولیدشده به‌صورت برنامه‌ای هستند (بدون کپی‌رایت) تا بتونی بلافاصله پخش واقعی رو تست کنی. برای استفاده‌ی نهایی، جایگزین‌شون کن با فایل‌های صوتی قانونی خودت با همون اسم یا با به‌روزرسانی مسیر `src` در `script.js`.
